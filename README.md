# front-end-Library-manage
📚 Library Management System

A responsive and interactive Library Management System developed using HTML5, CSS3, and JavaScript. This project helps manage library books, track book availability, issue and return books, and search for books through a simple user-friendly dashboard.

🚀 Features

Responsive dashboard design.

Add new books to the library.

View all available books.

Edit and update book details.

Delete books from the library.

Both Light and Dark Theme – Modern dark UI with gradient colors and interactive elements.

Interactive user interface.
🛠️ Technologies Used

HTML5 – Structure of the application.

CSS3 – Styling, layouts, animations, and responsive design.

JavaScript (ES6) – CRUD operations and dynamic functionality.

React- Components updates UI and State.
